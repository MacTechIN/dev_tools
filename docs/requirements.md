# 요구사항 명세서

- 상태: 초안 (2026-11-26)
- 근거: `dev_tools_definition.md`, `docs/ui_concept.html`, `docs/release_delivery.md`

이 문서는 dev_tools가 갖춰야 할 기능을 ID가 붙은 요구사항으로 나열한다. dev_tools 자체의 갭 탐지가 처음 읽을 스펙이기도 하다.

## 읽는 법

- **ID**: `REQ-영역-번호`. 한 번 붙인 ID는 바꾸거나 다시 쓰지 않는다.
- **우선**: 필수(없으면 그 단계가 끝나지 않음), 권장(있으면 좋음), 나중(첫 버전 이후).
- **단계**: `development_plan.md`의 단계 번호.

| 영역 | 뜻 |
|---|---|
| COL | 활동 수집 |
| DSH | 대시보드 화면 |
| TSK | 작업과 맡기(claim) |
| GAP | 갭 탐지 |
| CHK | 완료 확인 |
| CNF | 충돌 경고 |
| CHT | 팀 대화방 |
| MCP | AI 개발툴 안에서의 사용 |
| NTF | 알림 |
| ADM | 설치, 계정, 설정 |
| REL | 출시와 전달 |
| NFR | 품질 조건 |
