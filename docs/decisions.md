| D-28 | 어댑터의 수집 방식 | 모든 도구에서 command hook이 `devtools hook <도구>`를 실행하고, 공통 형식으로의 변환은 개발자 컴퓨터에서 한다. HTTP hook과 서버 쪽 변환 경로는 쓰지 않는다. Claude Code hook은 프로젝트의 개인 설정(`.claude/settings.local.json`)에, Codex hook은 사용자 설정(`~/.codex/hooks.json`)에 넣는다. Codex의 hook 신뢰 승인은 사용자가 직접 한다 | 실제 도구에서 확인한 결과 hook 입력에 프롬프트, 파일 내용, AI 응답이 들어 있어 원문을 컴퓨터 밖으로 보내지 않으려면 로컬 변환이 필요함. 프로젝트 공유 설정에 넣으면 저장소를 통해 다른 팀원에게 퍼짐. HTTP hook 주소 차단 문제도 없어짐 | 2026-11-27 |

D-23의 "Orca와 같은 방식"은 Orca(stablyai/orca)가 각 회사의 공식 CLI를 그대로 실행해 사용자가 자기 구독으로 로그인하게 하는 점을 가리키는 것으로 이해했다. 검색 결과의 README 요약으로만 확인했고 공식 문서는 열어 보지 않았다 **[미확인]**.
